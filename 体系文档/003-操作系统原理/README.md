# 操作系统原理手册

> **一句话**：操作系统 = 硬件与应用之间的总管家——管 CPU 时间、内存、外设与文件；嵌入式无论跑 Linux 还是 RTOS，都是它的形态变体。  
> **读者**：学过 C 与体系结构、想弄清"程序怎么被系统托管"的初学者；要理解 RTOS 与嵌入式 Linux 差异的工程师。  
> **口径**：概念通用为主线，例证 Linux（通用 OS）与 FreeRTOS（RTOS）双线对照；不深入内核源码，版本不绑定。  
> **更新**：2026-11-14  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

## 阅读约定

1. **概念通用，例证双线**：机制一律用"Linux（通用 OS）+ FreeRTOS（RTOS）"对照，看清同一原理的两种形态。
2. **不深入源码**：讲机制与数据流，不逐行读内核；版本不绑定，演进敏感处只写模式。
3. **每册结构统一**：目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
4. **跨册引用带册号**：如「计算机体系结构」002——所指章节必须真实存在。
5. **教学节带跟学四件套**：完整示例 → 预期输出（本机实测回填）→ 跟做步骤 → 试一试；本板块实验以本机可观察的进程/缓冲/竞态为主。
