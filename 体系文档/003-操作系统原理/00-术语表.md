# 00 术语表

> **这一文档回答**：操作系统词汇的准确定义、两个混用词的分界、「症状出现时病根在哪」往哪走。  
> **怎么用**：按名字（按册分组）、按缩写（缩写速查）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

### 000 操作系统原理全貌

| 术语 | 英文 | 一句话 |
|---|---|---|
| 操作系统 | Operating System | 管理硬件资源、给应用提供运行环境与服务的系统软件 |
| 内核 | Kernel | OS 的核心：调度、内存、文件、驱动都在这里，常驻内存 |
| 发行版 | Distribution | 内核 + 工具 + 应用打包成的可用系统（Ubuntu/Debian 等） |
| 引导程序 | Bootloader | 加电后把内核从存储搬到内存并启动它的一段程序（U-Boot/GRUB） |
| 根文件系统 | Root Filesystem | 内核启动后挂载的第一套文件系统，init 与库都在里面 |
| 实时性 | Real-time | 系统在确定时间内响应的能力；RTOS 的立身之本 |

### 001 操作系统的职责与启动

| 术语 | 英文 | 一句话 |
|---|---|---|
| 进程管理 | Process Management | 决定哪个程序什么时候上 CPU 跑 |
| 内存管理 | Memory Management | 给每个程序分内存、记归属、防互踩 |
| 文件系统 | File System | 把"磁盘上一堆块"抽象成"文件与目录" |
| 设备管理 | Device Management | 用驱动把千差万别的硬件统一成可调用接口 |
| 特权级 | Privilege Level | CPU 区分"应用能干的"与"只有内核能干的"硬件机制 |
| 宏内核 | Monolithic Kernel | 调度/文件/驱动全在一个大内核里跑（Linux） |
| 微内核 | Microkernel | 内核只留最小机制，服务放用户态进程（QNX/minix 思路） |

### 002 进程与线程

| 术语 | 英文 | 一句话 |
|---|---|---|
| 进程 | Process | 程序的一次运行：代码 + 资源 + 执行状态的组合 |
| 进程控制块 | Process Control Block | 内核里记录进程信息的结构体，进程的"档案" |
| 线程 | Thread | 进程内的执行流；同一进程的线程共享地址空间 |
| 上下文切换 | Context Switch | 内核保存当前执行流状态、换另一个上 CPU 的过程 |
| 调度器 | Scheduler | 决定"下一个上 CPU 的是谁"的内核模块 |
| 竞态条件 | Race Condition | 多个执行流争同一数据、结果依赖时序的隐患 |
| 互斥锁 | Mutex | 保证同一时刻只有一个执行流进临界区的同步工具 |

### 003 中断与系统调用

| 术语 | 英文 | 一句话 |
|---|---|---|
| 中断向量表 | Vector Table | "中断号→处理函数入口"的表，硬件找 ISR 靠它 |
| 中断服务程序 | Interrupt Service Routine | 中断到达后执行的处理函数，讲究快进快出 |
| 异常 | Exception | 程序自己触发的同步打断（除零、缺页、主动陷入） |
| 系统调用 | System Call | 用户程序请求内核服务的正式通道 |
| 用户态 | User Mode | 受限运行级别：不能直接碰硬件与内核内存 |
| 内核态 | Kernel Mode | 特权运行级别：可执行特权指令、访问全部内存 |
| 上下半部 | Top/Bottom Half | 中断处理的分工：上半部快进快出，重活留给下半部 |
| 前后台系统 | Foreground/Background | 裸机经典结构：大循环后台 + 中断前台 |

## 缩写速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| OS | Operating System | 操作系统 |
| PCB | Process Control Block | 进程控制块：内核里的进程档案 |
| ISR | Interrupt Service Routine | 中断服务程序 |
| IPC | Inter-Process Communication | 进程间通信：管道/消息/共享内存等机制总称 |
| RTOS | Real-Time Operating System | 实时操作系统：FreeRTOS/RT-Thread/Zephyr 等 |
| API | Application Programming Interface | 应用编程接口：程序之间约定的调用面 |

## 易混对

| A vs B | 分界一句话 |
|---|---|
| 程序 vs 进程 | 程序是磁盘上的文件，进程是它的一次运行 |
| 进程 vs 线程 | 进程有独立地址空间，线程共享所属进程的地址空间 |
| 并发 vs 并行 | 并发是"交替上 CPU 看似同时"，并行是"真有多核同时跑" |
| 中断 vs 异常 | 中断是外设异步打断，异常是指令执行中的同步打断 |
| 系统调用 vs 函数调用 | 函数调用留在用户态，系统调用要穿越到内核态 |
| 宏内核 vs 微内核 | 服务都进内核（快但一崩全崩）vs 内核最小化（稳但消息开销） |
| 裸机 vs RTOS | 大循环+中断的前后台 vs 有调度器的多任务 |
| 通用 OS vs RTOS | 吞吐与功能优先 vs 响应时间确定优先；Linux 可打实时补丁但本性非实时 |
