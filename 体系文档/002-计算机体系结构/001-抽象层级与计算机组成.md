## 1.1 抽象层级：下层提供服务，上层只管用

**定义**：计算机的一切按"层"组织——每层只依赖下一层的接口、对上层提供服务；理解了分层，任何新技术都能找到它的落点。这就是本库贯穿主线一（根 README）。

| 层（自底向上） | 是什么 | 本库对应册 |
|---|---|---|
| 晶体管 | 最小开关单元：导通/截止两种状态 | 「004 电子电路」（规划） |
| 逻辑门 | 晶体管组成与/或/非运算 | 「004 电子电路」（规划） |
| 部件 | CPU、存储器、外设控制器 | 本板块 002/003 |
| 指令集（ISA） | 软件与硬件的契约 | 本板块 002 |
| 固件/驱动 | 面向硬件的第一层软件 | 「C语言」003 §3.6 铺垫，实操归规划 005/007 |
| 操作系统 | 硬件资源的总管家 | 「操作系统原理」全板块 |
| 应用 | 你写的程序 | 「C语言」全板块 |

**机制**：分层的收益是**替换自由**——同一 ISA 上换任何芯片，软件不用改；同一 OS 接口上换任何硬件，应用不用改。代价是每层封装都藏了细节，"卡在哪一层"是排障的第一问。

**练习**：把"printf 打不出字"放进塔里：应用层调用（C 语言）→ 系统调用进内核（OS 003）→ 驱动（规划 005/007）→ 外设硬件（规划 005）——一条排查路径就是一次下塔。

## 1.2 冯·诺依曼与哈佛：指令和数据放不放一起

**冯·诺依曼结构**：指令与数据放在**同一个**存储器，走同一条通道——"存储程序"思想：程序像数据一样存在存储器里，换程序 = 换存储内容，计算机因此成为通用机器。

**哈佛结构**：指令与数据**分开**存储、分开通道——取指令与取数据可以同时进行。ARM Cortex-M 是标准哈佛：程序放 Flash、变量放 SRAM，两条通道并行。

| | 冯·诺依曼 | 哈佛 |
|---|---|---|
| 指令与数据存储 | 同一存储器 | 分开存储 |
| 通道 | 共享，可能互相等 | 独立，可并行 |
| 现例 | 通用 PC 的演化主形（缓存调和） | Cortex-M 级 MCU |

**为什么它不只是考试概念**：它解释了 MCU 的内存现实——程序在 Flash、变量在 SRAM，两边的容量、速度、寿命完全不同（本板块 003 §3.3 全部建立在这上面）。

## 1.3 五大部件与三种硬件形态：MCU / SoC / PC

**五大部件**：运算器（ALU，真做运算的）、控制器（指挥取指执行的，合起来是 CPU）、存储器、输入设备、输出设备。现代芯片把五件套不同程度地集成：

| | MCU（微控制器） | SoC（片上系统） | PC |
|---|---|---|---|
| 典型芯片 | STM32、ESP32 的 MCU 核 | 骁龙、树莓派的 BCM | 台式机/笔记本 CPU |
| 内存规模 | KB 级（Flash+SRAM） | MB~GB 级 | GB 级 |
| 跑什么 | 裸机 / RTOS | 嵌入式 Linux / Android | 桌面 OS |
| 典型任务 | 控制一个电机、采一个温度 | 手机、网关、智能设备 | 通用计算 |
| 开发方式 | 本机交叉编译 + 烧录 | 交叉编译 + 系统构建 | 本机编译 |

**嵌入式两条载体线**（根 README 主线三）就是 MCU 与 SoC：前者轻、实时、直接操作外设；后者像"缩小版 PC"，OS 管一切。本板块 002/003 的所有机制都会对这两条线各说一遍。

**观察与判断**：拿到一块陌生芯片，先问三句——字长多少（§1.4）、内存多大放哪（003）、有没有 OS（线一还是线二），选型与学习路径立刻清晰。

## 1.4 信息的二进制表示：进制、位与补码

**二进制是硬件的母语**：晶体管只有通/断两态，所以信息用 0/1 表示。十六进制（0x）是二进制的缩写形式——1 位 hex 对应 4 位二进制，`0xFF` 就是 `1111 1111`，读寄存器时人眼友好。

| 单位 | 含义 | 注意 |
|---|---|---|
| bit（位） | 一个 0/1 | 带宽单位用 bit/s |
| byte（字节） | 8 bit | 容量单位用 byte；带宽 100 Mbps ≠ 100 MB/s |
| word（字） | 与字长同义 | 32 位机的字是 4 字节 |

**字长**：CPU 一次能处理的位数（8/16/32/64）——它决定寄存器宽度、一次运算的规模、以及地址编号的上限。跨平台 C 代码用定宽类型 `uint32_t`（「C语言」002 §2.1）把差异钉死。

**补码**：硬件表示负数的方案——正数照写，负数"按位取反加一"。它让加法电路不用为负数做任何特殊设计：`-1` 就是全 1（如 32 位的 `0xFFFFFFFF`），加 1 自然回绕到 0。观察法：`printf("%d\n", 0xFFFFFFFF);` 会打印 -1——同一串二进制，解释方式不同结果不同（「C语言」002 §2.1 的"类型 = 宽度 + 解释"在硬件层的回声）。

**字节序**：多字节值在内存里从低位还是高位字节排起（小端/大端），不同平台不同——跨设备传二进制数据时的经典坑，遇到再查表，本册立名词。
