# 00 术语表

> **这一文档回答**：体系结构词汇的准确定义、两个混用词的分界、「症状出现时病根在哪」往哪走。  
> **怎么用**：按名字（按册分组）、按缩写（缩写速查）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

### 000 计算机体系结构全貌

| 术语 | 英文 | 一句话 |
|---|---|---|
| 抽象层级 | Abstraction Level | 计算机按"下层提供服务、上层只管用"分层堆叠的组织方式 |
| 冯·诺依曼结构 | von Neumann Architecture | 指令与数据放同一个存储器的经典结构 |
| 哈佛结构 | Harvard Architecture | 指令与数据分开放的存储结构，可同时取指令和取数据 |
| 微控制器 | Microcontroller | CPU+内存+外设集成在一颗芯片上的单芯片计算机 |
| 片上系统 | System on Chip | 把计算、存储、外设甚至无线能力集成在一颗芯片上的系统级方案 |
| 字长 | Word Size | CPU 一次能处理的位数（8/16/32/64 位），决定寄存器与地址宽度 |

### 001 抽象层级与计算机组成

| 术语 | 英文 | 一句话 |
|---|---|---|
| 晶体管 | Transistor | 组成一切数字硬件的最小开关单元 |
| 逻辑门 | Logic Gate | 晶体管组合出的与/或/非等基本运算单元 |
| 存储程序 | Stored Program | 程序像数据一样存在存储器里——计算机能"换程序"的根本 |
| 固件 | Firmware | 烧写在非易失存储里、设备出厂就带的底层软件 |
| 补码 | Two's Complement | 硬件表示负数的方式：加法电路不用为负数做特殊设计 |
| 字节序 | Byte Order | 多字节值在内存里的排列顺序（大端/小端），跨平台传数据必踩 |

### 002 CPU与指令集

| 术语 | 英文 | 一句话 |
|---|---|---|
| 程序计数器 | Program Counter | 存"下一条指令地址"的专用寄存器，程序前进的方向盘 |
| 指令周期 | Instruction Cycle | CPU 取指→译码→执行（→访存/写回）的循环 |
| 机器码 | Machine Code | CPU 直接认识的二进制指令序列 |
| 汇编语言 | Assembly Language | 机器码的可读助记形式，与指令一一对应 |
| 精简指令集 | RISC | 指令少而规整、单条简单，靠组合完成复杂操作（ARM/RISC-V） |
| 复杂指令集 | CISC | 指令多而丰富、单条能干多步（x86） |
| 中断 | Interrupt | 外设"举手"打断 CPU 当前工作、转去处理的机制 |

### 003 存储层次与缓存

| 术语 | 英文 | 一句话 |
|---|---|---|
| 存储层次 | Memory Hierarchy | 寄存器→缓存→内存→Flash/磁盘的金字塔：越快越小越贵 |
| 缓存命中 | Cache Hit | CPU 要的数据恰好在上层缓存里，不用去慢速层取 |
| 局部性原理 | Locality | 刚用过的还会用（时间）、用过的旁边也快被用（空间）——缓存有效的根 |
| 易失性存储 | Volatile Memory | 断电数据即失：SRAM/DRAM |
| 非易失性存储 | Non-volatile Memory | 断电数据保留：Flash/EEPROM/磁盘 |
| SRAM | Static RAM | 静态随机存储器：快、贵、容量小——缓存与 MCU 内存的材质 |
| DRAM | Dynamic RAM | 动态随机存储器：慢于 SRAM 但便宜量大——PC/手机内存条的材质 |

## 缩写速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| ISA | Instruction Set Architecture | 指令集架构：软件与硬件之间"说什么话"的契约 |
| ALU | Arithmetic Logic Unit | 算术逻辑单元：CPU 里真正做运算的部件 |
| MCU | Microcontroller Unit | 微控制器：单芯片计算机，嵌入式第一线的硬件形态 |
| SoC | System on Chip | 片上系统：MCU 的放大版，常带 GPU/无线等系统级能力 |
| DMA | Direct Memory Access | 直接存储器访问：外设与内存直传数据，绕过 CPU |
| MMU | Memory Management Unit | 内存管理单元：做虚拟地址→物理地址翻译的硬件（OS 板块衔接） |

## 易混对

| A vs B | 分界一句话 |
|---|---|
| 冯·诺依曼 vs 哈佛 | 指令数据同存储 vs 分存储；现代 PC 是演化混合体，Cortex-M 是标准哈佛 |
| MCU vs SoC | 单芯片"够用就行"的控制器 vs 系统级能力集成的处理器；RTOS vs Linux 两条线 |
| SRAM vs DRAM | 静态不用刷新、快而贵 vs 动态要周期刷新、慢而便宜 |
| RAM vs Flash | 断电丢（跑程序）vs 断电留（存程序），嵌入式里一个都不能少 |
| 机器码 vs 汇编语言 | 同一东西：CPU 认的二进制 vs 人读的助记符，一一对应 |
| 指令集 vs 微架构 | ISA 是"对外契约"，微架构是厂商内部"怎么实现"；同 ISA 可有不同微架构 |
| 位 vs 字节 | 1 byte = 8 bit；带宽用 bit/s、容量用 byte，差 8 倍的经典误读 |
| 程序计数器 PC vs 个人电脑 PC | CPU 里的寄存器 vs 那台机器——上下文定含义 |

| 症状 | 最可能病根 | 去哪册哪节 |
|---|---|---|

| 程序"突然"跳到别处执行 | 中断打断了主流程 | 002 §2.5 |
| 同样的代码 PC 秒开 MCU 卡住 | 速度差千倍的存储与主频量级 | 003 §3.1 |
| 按序遍历数组比乱序快很多 | 缓存局部性在起作用 | 003 §3.2 |
| `sizeof(int)` 两台机器不一样 | 字长与 ABI 差异 | 001 §1.4 |
| 想定位问题却看不懂反汇编 | 不会读汇编的取指执行视角 | 002 §2.3 |
