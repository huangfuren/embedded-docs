# 计算机体系结构手册

> **一句话**：程序最终跑在什么上面——CPU 怎么执行指令、数据放在哪、硬件怎么组织；看懂机器，才能看懂嵌入式。  
> **读者**：学完或正在学 C 语言、想知道"代码底下发生什么"的初学者；要做 MCU/嵌入式 Linux 选型判断的工程师。  
> **口径**：概念通用为主线，例证用 ARM Cortex-M（微控制器）与 x86/ARM64（应用处理器）双线对照；数字给量级不绑具体型号；不深入微架构流水线。  
> **更新**：2026-11-14  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

> **与「C语言」的分界**：那边教"怎么写、怎么编"，本板块教"写出来的东西机器怎么跑"——C 001 的目标文件在本板块 002 被拆开看。
> **与「操作系统原理」的分界**：本板块讲硬件本身；OS 是跑在硬件上的第一个大软件——启动链的硬件一段在 001，内核一段归 OS 001。
> **规划衔接**：外设寄存器逐个实操归「005 MCU 与外设」；逻辑门与时序电路设计归「004 电子电路」。

## 阅读约定

1. **概念通用，例证双线**：机制一律用"通用计算机 + 微控制器"两条线对照，不绑死某一家芯片。
2. **数字只给量级**：写"差 10~100 倍"，不写具体纳秒——型号间差异大，量级才可靠。
3. **每册结构统一**：目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 检查清单。
4. **跨册引用带册号**：如「C语言」003——所指章节必须真实存在。
