## 核心概念速览

1. **补码让加法电路通吃加减**：负数 = 按位取反加一；结果只有一个零。有符号溢出是 UB，无符号回绕是标准规定。
2. **`.data` 占 Flash，`.bss` 不占**：零初始化的 4 MB 数组不让固件变大（实测：文件只涨 530 字节）。
3. **一切跳转都是改 PC**：if、循环、函数返回、中断，硬件层没有区别。
4. **软件延时不成立**：`-O2` 会把空循环整段删掉（实测：1000 万次从 0.0041 s 变成 0.0000 s）。
5. **中断 = 硬件强制改 PC + 保存现场**：ISR 必须短、不能阻塞、不能调不可重入函数。
6. **Flash 有等待周期，SRAM 没有**：主频越高等得越多，这就是"标称 72 MHz 但算力不够"的原因。

## 误解澄清

| 常见误解 | 实际 |
| --- | --- |
| 72 MHz 的主频就能翻转 72 MHz 的 GPIO | 一次翻转是三条指令，还要过 Flash 等待、总线分频，实际只有几 MHz |
| 空循环可以精确延时 | 优化等级一改就没了；要精确时间用硬件定时器 |
| 全局变量上电都是 0 | 只有 `.bss` 是；放进 `noinit` 段的就是随机值 |
| `const` 大表占 RAM | 它在 `.rodata`，留在 Flash，不占 RAM，但占 Flash |
| MCU 上可以随便 malloc | 堆通常只有 KB 级，碎片几次就耗尽 |
| 中断服务函数里可以慢慢处理 | ISR 必须短，长逻辑要搬到主循环 |
| Cortex-M 都有 cache | M3/M4 没有，只有 M7 有 I-Cache/D-Cache |
| 浮点数可以直接 `==` 比较 | 必须 `fabs(a-b) < eps` |
| 大端小端只是内存排布，无所谓 | 跨设备传多字节值必踩，Modbus 就是大端 |
| 冯·诺依曼与哈佛只是课本概念 | 它决定了你的变量上电要不要被搬一次 |

## 阅读约定

1. **实测与规格分开标**：C 程序输出标"本机实录"；MCU 的周期数、频率标"规格值"并注明来源（数据手册/ARM 架构手册）。
2. **周期数只给算法与量级**：Flash 等待周期以 STM32F103 的公开对照表为例，具体查你的型号。
3. **每册结构统一**：导读块 → 目录 → 正文（★ 必会 / ○ 拓展）→ 坑表 → 自测 6 题 + 动手任务。
4. **教学四件套**：完整示例 → 预期输出 → 跟做步骤 → 试一试。
5. **跨册引用带册号与节号**：如 221 §221.2——所指章节必须真实存在。
