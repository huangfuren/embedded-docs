# 电子电路手册

> **一句话**：电是嵌入式的物理底座——电压/电流怎么走、数字 0/1 在电路上怎么表示、一块 MCU 板上的元件各干什么；看懂电路，才能看懂芯片手册里每一句"接个上拉"。  
> **读者**：纯软件背景转嵌入式、没摸过万用表的初学者；想看懂开发板电路图的工程师。  
> **口径**：只讲直流与入门数字电路，低压实验为主（USB 5V / 3.3V）；元件参数给典型值并注明"以 datasheet 为准"；不讲交流、电力电子与模拟设计深入。  
> **更新**：2026-11-14  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

## 阅读约定

1. **安全红线**：全部实验限于低压直流（≤5V）；任何涉及市电/大电流的内容一概不写不做（⚠️ 001 §1.5）。
2. **参数给典型值**：LED 压降 2V、上拉 10kΩ 这类数字都是典型值，正式设计以元件 datasheet 为准。
3. **每册结构统一**：目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
4. **跨册引用带册号**：如「计算机体系结构」001——所指章节必须真实存在。
5. **教学节带跟学四件套**：完整示例 → 预期输出 → 跟做步骤 → 试一试；本板块实验分两路——软件仿真（用 C 位运算模拟逻辑门，全机可跑）与实物观察（有面包板套装才做，无器材给纸上计算作业）。
