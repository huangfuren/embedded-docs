# 00 术语表

> **这一文档回答**：电子电路词汇的准确定义、两个混用词的分界、「症状出现时病根在哪」往哪走。  
> **怎么用**：按名字（按册分组）、按缩写（缩写速查）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

### 000 电子电路全貌

| 术语 | 英文 | 一句话 |
|---|---|---|
| 模拟信号 | Analog Signal | 连续变化的电信号（如麦克风输出），数值有无穷多档 |
| 数字信号 | Digital Signal | 只用少数离散电平（0/1）表示的信号，抗干扰是它的立身之本 |
| 电平 | Logic Level | 数字系统里代表 0/1 的电压区间，不是"有没有电" |
| 直流 | Direct Current | 方向不变的电流；电池与 USB 供电都是直流 |
| 最小系统 | Minimum System | 让 MCU 能跑起来的最少电路：供电/复位/时钟/启动配置 |
| 驱动电流 | Drive Current | 输出脚能"推得动"的电流上限，超了就拉不动电平 |

### 001 电压电流与欧姆定律

| 术语 | 英文 | 一句话 |
|---|---|---|
| 电压 | Voltage | 推动电荷的"电压力"，单位伏特 V；两点之间的差值 |
| 电流 | Current | 电荷流动的"流量"，单位安培 A；mA 是电子世界常客 |
| 电阻 | Resistance | 对电流的阻碍，单位欧姆 Ω |
| 欧姆定律 | Ohm's Law | U = I × R：三要素永远满足的关系，电路计算的总钥匙 |
| 功率 | Power | P = U × I，元件发热的根源；超功率 = 发烫烧毁 |
| 分压 | Voltage Divider | 两只电阻串联把电压"按比例"分出来，ADC 采样的经典前置 |
| 上拉电阻 | Pull-up Resistor | 把悬空引脚钉在高电位的电阻，按键与总线标配 |

### 002 逻辑门与数字信号

| 术语 | 英文 | 一句话 |
|---|---|---|
| 逻辑门 | Logic Gate | 实现基本逻辑运算的电路单元：与/或/非 |
| 真值表 | Truth Table | 列出输入所有组合对应输出的表，读懂门的第一工具 |
| 异或 | XOR | 两输入不同输出 1、相同输出 0；加法器的核心 |
| 组合逻辑 | Combinational Logic | 输出只由当前输入决定，没有记忆 |
| 时序逻辑 | Sequential Logic | 输出还依赖历史状态，有"记忆" |
| 触发器 | Flip-flop | 能记住一位 0/1 的最小时序单元，边沿触发 |
| 噪声容限 | Noise Margin | 高/低电平区间与判定阈值之间的安全余量 |

### 003 元器件与MCU最小系统

| 术语 | 英文 | 一句话 |
|---|---|---|
| 电阻器 | Resistor | 限流、分压、上拉的三栖主力 |
| 电容器 | Capacitor | 储存电荷的小水库：滤波/耦合/去耦 |
| 发光二极管 | LED | 通电发光、有极性的指示灯 |
| 二极管 | Diode | 只许电流单向通过的"阀门" |
| 晶体管 | Transistor | 用小电流/小电压控制大电流的电子开关（三极管/MOS） |
| 晶振 | Crystal | 提供稳定时钟节拍的振荡元件，CPU 的心跳 |
| 复位电路 | Reset Circuit | 保证芯片上电从干净状态开始跑的电路 |
| 启动配置 | Boot Configuration | 决定芯片上电后"从哪里、以什么方式"启动的引脚配置 |

## 缩写速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| DC | Direct Current | 直流 |
| GND | Ground | 地：电路的公共参考点，测电压的 0 点 |
| GPIO | General Purpose Input/Output | 通用输入输出引脚，MCU 与外界对话的手 |
| IC | Integrated Circuit | 集成电路：把大量晶体管封进一颗芯片 |
| PCB | Printed Circuit Board | 印制电路板：元件的"楼层"与"走线"载体 |
| MOSFET | Metal-Oxide-Semiconductor FET | 场效应管：电压控制的电子开关，数字芯片的原子 |

## 易混对

| A vs B | 分界一句话 |
|---|---|
| 电压 vs 电流 | 电压是"推力"，电流是"流量"；没推力就没流量 |
| 串联 vs 并联 | 串联分压、同一条路；并联分流、两条路 |
| 上拉 vs 下拉 | 悬空脚钉在高电平 vs 钉在低电平；按键电路二选一 |
| 模拟 vs 数字 | 连续无穷档 vs 离散 0/1；ADC/DAC 是两界的翻译官 |
| LED vs 普通二极管 | 会发光 vs 只整流；都有极性，接反不工作 |
| 触发器 vs 锁存器 | 边沿触发（时钟跳变瞬间）vs 电平敏感（使能期间跟随） |
| 高电平有效 vs 低电平有效 | 信号拉高动作 vs 拉低动作；看芯片手册信号名上的横线 |
| 去耦 vs 滤波 | 就近补给芯片瞬间的电流抽水 vs 把波动抹平 |

## 症状反查

| 症状 | 最可能病根 | 去哪册哪节 |
|---|---|---|
| LED 怎么都不亮 | 没串限流电阻/极性接反/电流不够 | 003 §3.4 |
| 芯片偶发复位、行为诡异 | 电源脚没加去耦电容 | 003 §3.2 |
| GPIO 输入脚读数乱跳 | 引脚悬空，没上拉/下拉 | 001 §1.4 |
| 按键完全没反应 | 按键电路没配上拉或接线错 | 001 §1.4 |
| 元件/芯片发烫 | 电流超限或短路 | 001 §1.2 |
| 烧录器连不上、程序不跑 | BOOT 启动配置没设对 | 003 §3.3 |
| 万用表读数乱跳、量不出 | 档位/量程选错 | 001 §1.5 |
| 芯片摸过之后莫名失灵 | 静电击穿 CMOS | 002 §2.5 |
