# 401 术语表

> **这一文档回答**：硬件基础词汇的准确定义、「症状出现时病根在哪」往哪走。  
> **怎么用**：按名字（按技术模块分组）、按缩写（表内「缩写」列）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按模块分组

### 410 电学基础（411 · 412 · 413）

| 术语 | 缩写 | 英文 | 一句话 |
|---|---|---|---|
| 电荷 | — | Charge | 物质带电的基本量，单位库仑 C；1C ≈ 6.24×10¹⁸ 个电子 |
| 电流 | — | Current | 电荷定向移动的"流量"，单位安培 A；方向按正电荷定义 |
| 电压 | — | Voltage | 推动电荷的"电压力"，单位伏特 V；永远是两点之间的差值 |
| 电阻 | — | Resistance | 对电流的阻碍，单位欧姆 Ω；由材料与几何决定，不随电压变 |
| 欧姆定律 | — | Ohm's Law | U = I × R：三要素永远满足的关系，电路计算的总钥匙 |
| 功率 | — | Power | P = U×I = I²R：元件发热的速率，超功率就烧 |
| 焦耳定律 | — | Joule's Law | Q = I²Rt：热量与电流平方、电阻、时间成正比 |
| 额定功率 | — | Rated Power | 元件长期连续安全工作可耗散的最大功率（1/8W、1/4W…） |
| 安全电压 | — | Safety Voltage | 国标：交流 36V 以下、直流 24V 以下 |
| 直流 | DC | Direct Current | 大小与方向不随时间周期性变化，电池与 USB 都是 |
| 交流 | AC | Alternating Current | 大小与方向随时间周期性变化，入户 220V 是 |
| 短路 | — | Short Circuit | 电源正负直连，电流只受内阻限制，瞬间发热损坏器件 |
| 漏电保护器 | RCD | Residual Current Device | 检测火线流出与零线流入的电流差，超 30mA 跳闸 |
| 地 | GND | Ground | 电路的公共参考点，测电压的 0 点 |
| 电源正极 | VCC | Voltage Common Collector | 板上主供电轨，芯片的供电入口 |

### 420 电路拓扑（421 · 422）

| 术语 | 缩写 | 英文 | 一句话 |
|---|---|---|---|
| 串联 | — | Series | 一条路：电流相等、电压相加、电阻相加（分压） |
| 并联 | — | Parallel | 两条路：电压相等、电流相加、电阻倒数相加（分流） |
| 分压 | — | Voltage Divider | 两只电阻串联按比例取电压，Vout = Vin×R2/(R1+R2) |
| 分流 | — | Current Divider | 两只电阻并联分开电流，按电阻反比分配 |
| 负载效应 | — | Loading Effect | 分压电路接上吃电流的负载后输出被拉低 |
| 上拉电阻 | — | Pull-up Resistor | 把引脚钉在高电位的普通电阻，按键与总线标配 |
| 下拉电阻 | — | Pull-down Resistor | 把引脚钉在低电位的普通电阻 |
| 高阻态 | — | High-Z | 引脚既不接电源也不接地，不提供电平，读数随机 |

### 430 无源器件（431 · 432 · 433）

| 术语 | 缩写 | 英文 | 一句话 |
|---|---|---|---|
| 插件式 | — | Through-Hole | 引脚穿过 PCB 焊接，体积大、好手工焊 |
| 贴片式 | SMD | Surface Mount Device | 直接贴焊在板面，小、适合机器贴装 |
| 丝印 | — | Marking / Silkscreen | 元件表面的字符标记，用来读出阻值或型号 |
| 电阻器 | — | Resistor | 限流、分压、上拉的三栖主力 |
| 容差 | — | Tolerance | 实际值与标称值的允许偏差（±5% / ±1% / ±0.1%） |
| EIA-96 标法 | EIA-96 | EIA-96 Marking | 两位数字查表 + 一位字母乘数的精密电阻标法 |
| 色环法 | — | Color Code | 用彩色环带表示阻值与精度，实战建议改用万用表量 |
| 电容器 | — | Capacitor | 储存电荷的小水库：滤波/耦合/旁路/去耦 |
| 耐压值 | — | Rated Voltage | 电容能承受的最大电压，超了击穿甚至爆浆 |
| 容抗 | — | Capacitive Reactance | Xc = 1/(2πfC)：电容对交流的阻碍，频率越高阻碍越小 |
| 滤波 / 耦合 | — | Filtering / Coupling | 对地并联抹平波动 vs 串联隔掉直流 |
| 旁路 / 去耦 | — | Bypass / Decoupling | 把高频噪声引走 vs 给芯片就近供电 |
| 电感器 | — | Inductor | 把电能转成磁能存储的元件，通直流、阻交流 |
| 感抗 | — | Inductive Reactance | XL = 2πfL：电感对交流的阻碍，频率越高阻碍越大 |
| 直流电阻 | DCR | DC Resistance | 电感线圈本身的直流电阻，等效于串联一只小电阻 |
| 继电器 | — | Relay | 用小电流控制大电流的机械开关，线圈通电吸合触点 |
| 续流二极管 | — | Freewheeling Diode | 反向并联在电感负载两端，断电时泄放反电动势 |
| 保险丝 | — | Fuse | 故意做脆弱的电阻，电流超额定值熔断保护后级 |
| 接插件 | — | Connector | 把不同设备连起来，关键参数是脚间距（2.54mm 最常见） |
| 有源蜂鸣器 | — | Active Buzzer | 内含振荡电路，通电就响 |
| 无源蜂鸣器 | — | Passive Buzzer | 必须外部给方波才响，欧姆档有读数可判别 |
| 稳压芯片 | LDO | Voltage Regulator | 把不稳定输入变成稳定输出；LDO 是低压差类型 |

### 440 半导体器件（441 · 442 · 443）

| 术语 | 缩写 | 英文 | 一句话 |
|---|---|---|---|
| 本征半导体 | — | Intrinsic Semiconductor | 纯净无缺陷的半导体，载流子靠热激发，导电能力弱 |
| 掺杂 | — | Doping | 往硅里加杂质以可控地制造载流子 |
| N 型半导体 | — | N-type | 掺五价元素（磷），多子是自由电子 |
| P 型半导体 | — | P-type | 掺三价元素（硼），多子是空穴 |
| 载流子 | — | Carrier | 能自由移动并形成电流的带电微粒：电子与空穴 |
| 空穴 | — | Hole | 电子离开共价键后留下的空位，视为带正电的载流子 |
| PN 结 | — | PN Junction | P 型与 N 型交界处形成的结构，单向导电的基本单元 |
| 耗尽层 | — | Depletion Region | PN 结交界面载流子被清空、只剩固定离子的区域 |
| 正向偏置 | — | Forward Bias | P 接高 N 接低，耗尽层变窄，导通 |
| 反向偏置 | — | Reverse Bias | P 接低 N 接高，耗尽层变宽，截止 |
| 击穿 | — | Breakdown | 反向电压过大导致反向电流骤增（雪崩/齐纳） |
| 二极管 | — | Diode | 一个 PN 结 + 两个引脚，只允许单向导通 |
| 发光二极管 | LED | Light Emitting Diode | 正向导通时发光的二极管，必须串限流电阻 |
| 三极管 | BJT | Bipolar Junction Transistor | 两个 PN 结，基极电流控制集电极电流 |
| 基极 | B | Base | 控制端：B-E 间正向偏置，一小股基极电流决定 C-E 的大电流 |
| 集电极 | C | Collector | 收集端：载流子从发射极穿过基区被它收走，电流由基极控制 |
| 发射极 | E | Emitter | 发射端：载流子从这里注入，NPN 中电流由 E 流向 GND |
| 放大倍数 | β (hFE) | Current Gain | IC = β × IB，β 常为几十到几百；饱和时不再适用 |
| 饱和 | — | Saturation | 三极管导通到极限，C-E 间压降约 0.2V，开关的"开" |
| 达林顿管 | — | Darlington | 两只三极管级联，β 相乘但饱和压降更高 |
| 光耦 | — | Optocoupler | LED + 光敏管，用光传信号，实现电气隔离 |
| MOS 管 | MOSFET | Metal-Oxide-Semiconductor FET | 栅极电压控制沟道通断的场效应管，芯片的最小单位 |
| 阈值电压 | Vth | Threshold Voltage | 让 MOS 沟道形成的最小栅源电压 |
| 导通电阻 | Rds(on) | On-Resistance | MOS 导通时 D-S 之间的电阻，是发热的主因 |
| 体二极管 | — | Body Diode | MOS 内部 D-S 之间寄生的二极管，限制其双向截止能力 |

### 450 板级实践（451 · 452 · 453 · 454）

| 术语 | 缩写 | 英文 | 一句话 |
|---|---|---|---|
| 最小系统 | — | Minimum System | 让 MCU 能跑起来的最少电路：供电/复位/时钟/启动配置 |
| 复位电路 | — | Reset Circuit | 保证芯片上电从干净状态开始跑的电路 |
| 晶振 | — | Crystal Oscillator | 提供稳定时钟节拍的元件，CPU 的心跳 |
| 启动配置 | — | Boot Configuration | 决定芯片上电后从哪里、以什么方式启动的引脚电平 |
| 驱动电流 | — | Drive Current | 输出脚能"推得动"的电流上限，超了就拉不动电平 |
| 拉电流 | — | Current Sourcing | 引脚往外推电流点亮负载（高电平有效） |
| 灌电流 | — | Current Sinking | 电流从外部灌进引脚（低电平有效），能力通常更强 |
| 推挽输出 | — | Push-Pull | 能主动输出高也能主动输出低，会与其他输出冲突 |
| 开漏输出 | — | Open-Drain | 只能主动拉低，高电平靠外部上拉，总线上不冲突 |
| 迟滞 | — | Hysteresis | 让"开"与"关"用两个不同阈值，避免临界点反复翻转 |
| 恒压 / 恒流 | CV / CC | Constant Voltage / Constant Current | 稳压电源两种工作状态；CC 灯亮说明进入限流 |
| 通用输入输出 | GPIO | General Purpose Input/Output | 通用输入输出引脚，MCU 与外界对话的手 |
| 集成电路 | IC | Integrated Circuit | 把大量晶体管封进一颗芯片 |
| 印制电路板 | PCB | Printed Circuit Board | 元件的"楼层"与走线载体 |
| 模数转换器 | ADC | Analog-to-Digital Converter | 把连续电压变成数字量 |

## 症状反查

| 症状 | 最可能病根 | 去哪册哪节 |
|---|---|---|
| LED 怎么都不亮 | 极性接反 / 没串限流电阻 / 引脚没初始化 | 452 §452.2 |
| 电阻读出来差 1000 倍 | 把 EIA-96 的 `10E` 当成三位法的 `103` | 431 §431.5 |
| 电解电容爆浆 | 有极性，接反了 | 431 §431.2 |
| 电容 `104` 算错成 104pF | 单位是 pF 且要补零，实际 100nF | 432 §432.2 |
| 芯片偶发复位、行为诡异 | 电源脚没加去耦电容 | 432 §432.6 |
| 烧录器连不上、程序不跑 | BOOT 启动配置没设对 | 451 §451.5 |
| GPIO 输入脚读数乱跳 | 引脚悬空，没上拉/下拉 | 422 §422.2 |
| 三极管一接上就烧 | 基极没串电阻，B-E 结直接短路 | 442 §442.5 |
| 三极管发烫但负载不工作 | 工作在放大区没进饱和区 | 442 §442.4 |
| MOS 管一上电就导通 | 栅极悬空被感应电压打开 | 443 §443.3 |
| 驱动继电器把引脚烧了 | 超 GPIO 驱动能力，且没加续流二极管 | 452 §452.4 |
| 串口偶尔乱码 | 用内部 RC，时钟精度不够 | 451 §451.4 |
| 稳压芯片烫手 | 压差 × 电流全变成热 | 433 §433.7 |
| 稳压电源电压被拉低 | 进了 CC 恒流模式 | 454 §454.4 |
| 数码管显示全乱 | 共阴/共阳选错 | 441 §441.6 |
| 万用表读数怪异 | 档位/接法错，或测量中拨了量程 | 454 §454.2 |
| 光感灯临界光照下闪 | 开环无迟滞，灯自身照到传感器 | 453 §453.5 |
| 继电器断电瞬间烧驱动管 | 线圈反电动势没泄放 | 433 §433.3 |
| 上电就冒烟 | 电源正负短路 | 413 §413.3 |
