# 数字电路手册

> **一句话**：数字电路回答"0 和 1 在导线上一副什么模样"——用什么电压算 1、用什么门能把两个数加起来、用什么单元能把一位状态记住、又怎么把这几件零件接成一台能跑程序的机器。  
> **读者**：学完「004 硬件基础」、已经认识二极管三极管 MOS 的初学者；想弄懂"位运算在硬件层到底做了什么"的软件工程师。  
> **口径**：以 3.3V CMOS 系统为例；电平与阈值给典型值，判定标准以具体芯片 datasheet 为准；不做门级电路设计与时序分析（那是数字 IC 设计）。  
> **更新**：2026-11-21  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

> **这条线为什么是这个顺序**：001 给表示法与最小记忆 → 002 把门拼成运算器 → 003 把门拼成存储单元 → 004 给存储单元配上"地址" → 005 用一条指令把三者串起来。**每一册都只用前面已经造好的零件**，不跳步。

> **后续扩充方向**：**600 MCU 与外设**（已规划）——把这台机器接到真实引脚、定时器、中断与串口上；本板块到 005 收尾，再往上就是体系结构与 ISA 的领域。

> **与「400 硬件基础」的分界**：440 讲到器件为止——PN 结、三极管、MOS 管的物理；本板块从"用这些器件搭出的门"开始往上，不重复器件原理。
> **与「002 计算机体系结构」的分界**：本板块管"门怎么组合成功能块、几条指令怎么跑起来"，体系结构 001/002 管"完整的 CPU 怎么组织、ISA 怎么定契约"。
> **与「600 MCU 与外设」（规划）的分界**：本板块给寄存器与位的硬件直觉，具体芯片的寄存器操作与外设驱动归 600。

## 阅读约定

1. **每册结构统一**：导读块 → 目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
2. **实验全部走软件仿真**：真值表、加法器、ALU、锁存器、存储器、CPU 都用 C 的位运算当场跑出来（`gates.c` / `adder.c` / `alu.c` / `latch.c` / `mem.c` / `cpu.c`），**不需要买芯片**——这个板块是纯软件也能学完的。
3. **打印的输出都是真跑出来的**：每册"预期输出"都是本机 `gcc` 编译后的实际结果，不是编出来好看的；数字对不上就是你自己抄错了。
4. **跨册引用带册号**：如「422 §422.2」——所指章节必须真实存在。
5. **阈值不作定论**：3.3V CMOS 的 2.0V / 0.8V 是典型值，不同家族（TTL、LVCMOS、LVTTL）差别很大，跨电平系统一律查 datasheet。
6. **先有直觉再进公式**：噪声容限、建立保持时间这类概念先给画面感，公式留到需要时再引。
