# 数字电路手册

> **一句话**：数字电路回答"0 和 1 在导线上一副什么模样"——用什么电压算 1、用什么门能把两个数加起来、用什么单元能把一位状态记住；这一层立住，CPU 与寄存器的硬件形态才不是黑箱。  
> **读者**：学完「004 硬件基础」、已经认识二极管三极管 MOS 的初学者；想弄懂"位运算在硬件层到底做了什么"的软件工程师。  
> **口径**：以 3.3V CMOS 系统为例；电平与阈值给典型值，判定标准以具体芯片 datasheet 为准；不做门级电路设计与时序分析（那是数字 IC 设计）。  
> **更新**：2026-11-19  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

## 阅读约定

1. **每册结构统一**：导读块 → 目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
2. **实验走软件仿真**：真值表与半加器用 C 的位运算当场跑出来（`gates.c` 全机可复现），不需要买芯片——这一册是纯软件也能学完的数字电路。
3. **跨册引用带册号**：如「004 §4.3」——所指章节必须真实存在。
4. **阈值不作定论**：3.3V CMOS 的 2.0V / 0.8V 是典型值，不同家族（TTL、LVCMOS、LVTTL）差别很大，跨电平系统一律查 datasheet。
5. **先有直觉再进公式**：噪声容限、建立保持时间这类概念先给画面感，公式留到需要时再引。
