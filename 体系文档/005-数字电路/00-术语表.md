# 00 术语表

> **这一文档回答**：数字电路词汇的准确定义、两个混用词的分界、「症状出现时病根在哪」往哪走。  
> **怎么用**：按名字（按册分组）、按缩写（缩写速查）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

### 000 数字电路全貌

| 术语 | 英文 | 一句话 |
|---|---|---|
| 数字电路 | Digital Circuit | 用离散电平表示与处理信息的电路，抗干扰是它的立身之本 |
| 逻辑门 | Logic Gate | 实现基本逻辑运算的电路单元：与/或/非 |
| 组合逻辑 | Combinational Logic | 输出只由当前输入决定，没有记忆 |
| 时序逻辑 | Sequential Logic | 输出还依赖历史状态，有"记忆" |
| 触发器 | Flip-flop | 能记住一位 0/1 的最小时序单元，边沿触发 |
| 寄存器 | Register | 多个共用时钟的触发器并排，存一个多位数 |

### 001 逻辑门与数字信号

| 术语 | 英文 | 一句话 |
|---|---|---|
| 模拟信号 | Analog Signal | 连续变化的电信号，数值有无穷多档 |
| 数字信号 | Digital Signal | 只用少数离散电平（0/1）表示的信号 |
| 电平 | Logic Level | 数字系统里代表 0/1 的电压区间，不是"有没有电" |
| 禁止区 | Forbidden Zone | 高低电平之间的不确定电压带，落在里面读数随机 |
| 噪声容限 | Noise Margin | 电平区间与判定阈值之间的安全余量，越大越抗干扰 |
| 判定阈值 | Threshold | 芯片认定"这是 1"或"这是 0"的电压分界（VIH/VIL） |
| 与门 | AND Gate | 全 1 才输出 1，对应 C 的 `&&` |
| 或门 | OR Gate | 有 1 就输出 1，对应 C 的 `\|\|` |
| 非门 | NOT Gate | 输入取反，对应 C 的 `!` |
| 异或门 | XOR Gate | 两输入不同输出 1，是"不进位加法" |
| 与非门 | NAND Gate | 与门后接非门；单独一种就能拼出全部逻辑 |
| 逻辑完备性 | Functional Completeness | 只用一种门实现任意逻辑的能力，NAND 具备 |
| 真值表 | Truth Table | 列出输入所有组合对应输出的表 |
| 半加器 | Half Adder | 一位加法电路：和=异或、进位=与 |
| 进位 | Carry | 加法溢出到高位的量，1+1 时产生 |
| 时钟 | Clock | 让所有时序单元同步动作的节拍器，由晶振提供 |
| 边沿触发 | Edge Triggered | 只在时钟跳变瞬间采样，其余时间保持 |
| 传播延迟 | Propagation Delay | 信号穿过一级门所需时间，时钟频率的上限来源 |
| 集成度 | Integration Level | 一颗芯片里晶体管的数量级：门→加法器→MCU |
| 静电击穿 | ESD Damage | 人体静电击穿 CMOS 栅极绝缘层，芯片永久损坏 |

### 002 加法器与运算器

| 术语 | 英文 | 一句话 |
|---|---|---|
| 全加器 | Full Adder | 三位相加：A、B 与低位送来的进位；输出本位和与进位 |
| 行波进位加法器 | Ripple Carry Adder | 多个全加器串联，进位从最低位一路荡到最高位 |
| 超前进位 | Carry Lookahead | 用并行逻辑直接算出各位进位，不等前一位算完 |
| 运算选择码 | ALU Opcode | 用几位编码选择 ALU 走哪条运算路 |
| 截断 | Truncation | 结果超位宽时只留低 N 位，高位直接丢弃 |
| 补码 | Two's Complement | 取反加一表示负数，把减法变成加法 |
| 溢出 | Overflow | 结果超出位数能表示的范围，符号位被"挤错" |

### 003 锁存器触发器与寄存器

| 术语 | 英文 | 一句话 |
|---|---|---|
| 锁存器 | Latch | 使能期间一直跟着输入变，电平敏感 |
| 反馈 | Feedback | 输出接回输入，状态因此能自己保持住 |
| 透明 | Transparent | en=1 期间输入直通到输出，此时锁不住任何值 |
| 使能端 | Enable | 决定这个单元这一拍是否更新 |
| 复位 | Reset | 把状态统一清成已知值，避免上电随机态 |
| 寄存器堆 | Register File | 一组寄存器按地址选读选写，CPU 手边的抽屉柜 |

### 004 译码器与存储器

| 术语 | 英文 | 一句话 |
|---|---|---|
| 译码器 | Decoder | n 位地址译成 2ⁿ 根选中线，同一时刻只亮一根 |
| 地址 | Address | 指出"第几个单元"的编号 |
| 存储单元 | Memory Cell | 一个地址对应的一组位（本册是 8 位） |
| 写使能 | WE (Write Enable) | 允许写入的开关；为 0 时写操作被直接拒绝 |
| 输出使能 | OE (Output Enable) | 允许把内容放上总线，否则输出高阻 |
| 高阻态 | High-Z | 既不拉高也不拉低，等于从总线上让开 |
| 片选 | CS (Chip Select) | 选中整颗芯片，决定它是否参与总线 |
| 带电可擦写存储 | EEPROM | 掉电不丢、可擦写，但写入慢、寿命有限 |

### 005 从 ALU 到 MCU

| 术语 | 英文 | 一句话 |
|---|---|---|
| 冯诺依曼结构 | von Neumann Architecture | 程序与数据同住一个存储器，五部件按取指-执行的循环工作 |
| 存储程序 | Stored Program | 指令也是存储里的内容；改内容就换功能，不改电路 |
| 控制器 | CU (Control Unit) | 取指、译码、把 opcode 变成控制信号的部件 |
| 指令 | Instruction | 一组位，回答两件事：做什么 + 对谁做 |
| 操作码 | Opcode | 指令里表示"做什么"的那几位 |
| 位域 | Bit Field | 一条指令字里"哪几位管什么"的划分 |
| 程序计数器 | PC (Program Counter) | 记住下一条指令的地址，每取一条自动加一 |
| 累加器 | Accumulator | 参与运算并存放结果的寄存器 |
| 数据通路 | Datapath | 数据在部件之间流动的路径与沿途的开关 |
| 内存映射 I/O | Memory-mapped I/O | 把外设寄存器编进地址空间，用读写内存的指令驱动外设 |
| 流水灯 | Running Light | 依次点亮不同引脚的最小可跑程序，用来验证整条链通了 |

## 缩写速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| CMOS | Complementary MOS | 互补 MOS：NMOS+PMOS 配对，功耗低、抗扰强 |
| TTL | Transistor-Transistor Logic | 早期双极型逻辑家族，阈值与 CMOS 不同 |
| NAND | NOT-AND | 与非门，逻辑完备的最小单元 |
| XOR | Exclusive OR | 异或门，加法器的核心 |
| ALU | Arithmetic Logic Unit | 算术逻辑单元，加法器等运算电路的总装 |
| LSB | Least Significant Bit | 最低有效位，二进制最右边那一位 |
| MSB | Most Significant Bit | 最高有效位，决定符号与量级 |
| ESD | Electrostatic Discharge | 静电放电，芯片的头号隐形杀手 |
| CU | Control Unit | 控制单元，把 opcode 解成一组控制信号 |
| PC | Program Counter | 程序计数器，本质是个每次加一的累加器 |
| GPIO | General Purpose I/O | 通用输入输出引脚，最简外设 |
| I/O | Input / Output | 输入输出，五部件里与外部打交道的那一件 |

## 易混对

| A vs B | 分界一句话 |
|---|---|
| 模拟 vs 数字 | 连续无穷档 vs 离散 0/1；ADC/DAC 是两界的翻译官 |
| 组合 vs 时序 | 只看当前输入 vs 还看历史状态；差别在有没有记忆 |
| 触发器 vs 锁存器 | 边沿触发（跳变瞬间）vs 电平敏感（使能期间跟随） |
| 半加器 vs 全加器 | 不考虑低位进位 vs 考虑低位进位；多个全加器级联成多位加法 |
| 噪声容限 vs 判定阈值 | 余量有多大 vs 分界在哪；前者决定抗造程度 |
| 0 电平 vs 断电 | 明确的低电压区间 vs 没有供电；前者电路正常工作 |
| 高电平有效 vs 低电平有效 | 拉高动作 vs 拉低动作；看信号名上有没有横线 |
| 全加器 vs 多位加法器 | 一位带进位入口 vs 多个全加器把进位串起来 |
| 截断 vs 溢出 | 高位被丢弃（宽度不够）vs 符号位被挤错（数值超范围） |
| 读 vs 写 | 观察 vs 改变状态；写必须显式许可，读要防总线冲突 |
| 指令 vs 数据 | 都是一串位，区别只在"这一拍被送到哪" |
| opcode vs 地址 | 做什么 vs 对谁做；一个在高位、一个在低位 |
| 位域 vs 位掩码 | 划分"哪几位管什么" vs 把某几位取出来或改掉的手段 |
| 数字内存 vs GPIO | 同一套 opcode 与地址，靠 dev 一位分成两半 |

## 症状反查

| 症状 | 最可能病根 | 去哪册哪节 |
|---|---|---|
| 把 0 电平当成"没电" | 概念混同，误以为电路坏了 | 001 §1.1 |
| GPIO 输入读数乱跳 | 引脚悬空落在禁止区，没上拉/下拉 | 001 §1.1 / 「004 硬件基础」001 §1.6 |
| 3.3V 芯片接 5V 信号不认 | 阈值不匹配，超出 VIH | 001 §1.1 |
| 信号名上带横线看不懂 | 那是低电平有效的记号 | 001 §1.6 |
| 真值表背不下来 | 没逐行跑，靠死记 | 001 §1.2（gates.c 跑一遍） |
| 想不通位运算硬件层做了什么 | 没把 C 运算符与门对应起来 | 001 §1.2~1.3 |
| 寄存器为什么"只在边沿变" | 触发器是边沿触发，不是电平跟随 | 001 §1.4 |
| 摸过板子后芯片莫名失灵 | 静电击穿 CMOS | 001 §1.5 |
| 加法结果最高位不对 | 进位没接上，或位宽不够 | 002 §2.4 |
| 12 + 10 算出 6 | 只看了低四位，漏了 Cout | 002 §2.4 |
| 换个数就变成负数 | 补码下超出范围，符号位被挤错 | 002 §2.6 |
| 锁存器在 en 期间"抖" | 电平敏感，输入变化直接透传 | 003 §3.3 |
| 多位寄存器存进去对不上 | 各触发器没共用同一根时钟 | 003 §3.5 |
| 好几个存储单元一起被改 | 译码输出不互斥，或片选没接 | 004 §4.2 |
| 读出来全是 1 或乱码 | 多个输出同时驱动总线，或高阻没上拉 | 004 §4.5 |
| 指令执行了但结果不对 | 位域拆错，位移算反 | 005 §5.4 |
| 程序跑飞，第二条就乱 | PC 没递增，或指令地址线接错 | 005 §5.5 |
| 结果写进内存却读不到 | dev 位与预期相反 | 005 §5.6 |
