## 9.1 主函数参数：argc 与 argv ★

**定义**：`int main(int argc, char *argv[])` 的两个形参接收**命令行**给的参数——argc（argument count）是参数**个数**（至少为 1），argv（argument value）是**指针数组**（007 §7.3），每个元素是一个字符串。你双击图标时 GUI 替你传参；命令行里 `.\程序名 参数1 参数2` 是明牌传参。

**完整示例**（`args_demo.c`）：

```c
#include <stdio.h>

/* argc = argument count（参数个数，至少为 1）
 * argv = argument value（参数值数组，每个元素是一个字符串） */
int main(int argc, char *argv[])
{
    printf("argc = %d\n", argc);
    for (int i = 0; i < argc; i++)
    {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    /* 简单用法：把第一个命令行参数当名字用 */
    if (argc > 1)
        printf("hello, %s!\n", argv[1]);
    return 0;
}
```

**跟做**：`gcc -Wall args_demo.c -o args_demo.exe` → 先裸跑 `.\args_demo.exe`，再带参数 `.\args_demo.exe zhangsan 25`。**预期输出（本机实录）**——裸跑：

```text
argc = 1
argv[0] = F:\个人知识库-嵌入式\tmp\code-c\args_demo.exe
```

带参数运行：

```text
argc = 3
argv[0] = F:\个人知识库-嵌入式\tmp\code-c\args_demo.exe
argv[1] = zhangsan
argv[2] = 25
hello, zhangsan!
```

（实录路径在 tmp 演示目录；正式工程仍守 001 §1.3 的纯英文路径纪律。）

**三处必看的机制**：① **argv[0] 是程序自身的路径**，不是第一个用户参数——所以 argc 裸跑也是 1；用户参数从 `argv[1]` 开始，共 `argc-1` 个；② 命令行参数**全是字符串**——`argv[2]` 拿到的 "25" 是字符串，要当数字用得先转换（`atoi`/`sscanf`，§9.3 正好是工具）；③ `main` 的返回值约定：0 = 成功、非零 = 失败（001 §1.3 的退出码在这里有了语义）。

**试一试**：① 把 25 当数字用：`int n = atoi(argv[2]); printf("%d\n", n * 2);`（需 `#include <stdlib.h>`）验证输出 50；② ⚠️ 不带 if 保护直接 `printf("%s\n", argv[1])` 裸跑——`argv[argc]` 是标准保证的 NULL 终结槽，对 NULL 用 `%s` 是未定义行为（本机打印 `(null)`，别依赖任何库的兜底）。

## 9.2 sprintf：把数据格式化写进字符串 ★

**定义**：`sprintf(str, 格式串, ...)` 与 printf **只差第一个参数**——printf 输出到控制台（008 §8.1 的 stdout），sprintf 把同样的格式化结果**写进字符串**。用途：拼日志行、生成文件名、组装报文——任何"数据 → 文本"的场合。

**完整示例**（`sprintf_demo.c`）：

```c
#include <stdio.h>

int main(void)
{
    int age = 10;
    double score = 28.234;
    char name[] = "xiaotiantian";

    /* sprintf：把格式化数据写进字符串（第一个参数是目的地） */
    char output_string[100];
    sprintf(output_string, "I am %s, age %d, score %.2f", name, age, score);
    printf("格式化字符串: %s\n", output_string);

    /* 拼接日志行的常见用法 */
    char log[64];
    sprintf(log, "[%s] temperature=%d", "sensor1", 37);
    puts(log);
    return 0;
}
```

**跟做**：编译运行。**预期输出（本机实录）**：

```text
格式化字符串: I am xiaotiantian, age 10, score 28.23
[sensor1] temperature=37
```

**三处必看的机制**：① 方向以**第一个参数**为参照：printf 的第一参数是格式串（输出到屏幕），sprintf 的第一参数是**目的地字符串**——占位符体系完全复用（002 §2.2）；② `%s` 填 `name`、`%.2f` 管 28.234 → 28.23——格式化的精度控制在这里生效；③ sprintf **不检查目标容量**——`log[64]` 装 30 字符没问题，装 200 字符就是缓冲区溢出（003 §3.5），拼长字符串前先算账。

**试一试**：① ⚠️ 把 `log[64]` 改 `log[8]` 拼 `[sensor1] temperature=37`（24 字符）——编译照过、栈已越界；② 用 sprintf 生成带序号的文件名 `"data_%d.txt"`，配 008 §8.4 的 fopen 循环建三个文件。

## 9.3 sscanf：从字符串按格式读出数据 ★

**定义**：`sscanf(str, 格式串, 地址...)` 与 scanf 只差第一个参数——scanf 从**输入缓冲区**取数据（008 §8.2），sscanf 从**给定字符串**里按格式提取。返回值是**成功解析的项数**——它是"字符串 → 数据"的解析器，也是处理固定格式文本（日志、报文、日期串）的瑞士军刀。

**完整示例**（`sscanf_demo.c`）：

```c
#include <stdio.h>

int main(void)
{
    /* sscanf：从字符串里按格式提取数据（第一个参数是数据源） */
    char input_string[] = "alice score:45, bob score:55, carl score:60, tail=xyz";
    float score1, score2, score3;
    char chs[10];
    int got = sscanf(input_string, "alice score:%f, bob score:%f, carl score:%f, tail=%s",
                     &score1, &score2, &score3, chs);
    printf("got = %d\n", got);
    printf("score1 = %.2f, score2 = %.2f, score3 = %.2f, chs = %s\n",
           score1, score2, score3, chs);

    /* 经典用法：把字符串转数字（一次解析出多个字段） */
    char data[] = "2026-11-15";
    int y, m, d;
    sscanf(data, "%d-%d-%d", &y, &m, &d);
    printf("y=%d m=%d d=%d\n", y, m, d);
    return 0;
}
```

**跟做**：编译运行。**预期输出（本机实录）**：

```text
got = 4
score1 = 45.00, score2 = 55.00, score3 = 60.00, chs = xyz
y=2026 m=11 d=15
```

**三处必看的机制**：① 格式串里的**非空白字面字符是"逐字符匹配的锚"**——`"alice score:"` 里的字母、冒号、逗号必须与源串一字不差，锚对不上解析就地中断；格式串里的**空格**只要求源串对应位置"跳过一段空白"（有零个也算过）。② `got = 4`——返回值是成功解析的**项数**，用它判断解析成败：文本处理程序的标准句式是 `if (sscanf(...) == 期望项数)`；③ `%d-%d-%d` 一行拆出年月日——`%d` 读到 `-` 停，字面锚 `-` 再吃掉它，两个锚夹一个字段，这就是"把字符串转数字"比逐字符转换快的原因。

**试一试**：① 把格式串里的逗号删掉再跑——`got` 掉到多少、哪些字段没解析到，抄下结果；② 解析 `"192.168.1.1"`：`sscanf(ip, "%d.%d.%d.%d", &a,&b,&c,&d)` 四个整数。

## 9.4 变参函数：printf 家族的底座 ○

**定义**：`返回值 函数名(固定参数..., ...)` 声明**变参函数**（variadic function）——`...` 表示"参数个数与类型不定"。printf 能接受任意个参数，靠的就是它。读取不定参数用 `<stdarg.h>` 三件套：`va_list` 声明游标、`va_start` 定位第一个不定参数、`va_arg` 按类型逐个取、`va_end` 收尾。

**完整示例**（`varargs_demo.c`）：

```c
#include <stdio.h>
#include <stdarg.h>

/* 变参函数：前面必须至少有一个固定参数，... 表示"参数个数与类型不定" */
void show_num(int count, ...)
{
    va_list args;
    va_start(args, count); /* 让 args 指向第一个不定参数 */
    for (int i = 0; i < count; i++)
    {
        int num = va_arg(args, int); /* 按给定类型取下一个参数 */
        printf("%d ", num);
    }
    va_end(args); /* 清理 */
    printf("\n");
}

/* vprintf 版：把 va_list 直接交给 vprintf，等于"把不定参数转发给 printf" */
void show_msg(const char *fmt, ...)
{
    va_list args;
    va_start(args, fmt);
    vprintf(fmt, args);
    va_end(args);
}

int main(void)
{
    show_num(3, 10, 20, 30);
    show_num(5, 1, 2, 3, 4, 5);
    show_msg("分别是:%s,%s\n", "hello", "world");
    return 0;
}
```

**跟做**：编译运行。**预期输出（本机实录）**：

```text
10 20 30 
1 2 3 4 5 
分别是:hello,world
```

**三处必看的机制**：① **`...` 前必须至少有一个固定参数**——`count` 就是"路标"：变参函数没法自己知道有几个参数，得靠固定参数（个数）或格式串（printf 的占位符个数）告诉它；② `va_arg(args, int)` 的**类型必须与实参真实类型一致**——char/short 传进来已被提升为 int（002 §2.2 的提升规则在此兑现），写错类型读出来就是垃圾；③ `vprintf(fmt, args)` 是"转发专用口"：写自己的日志函数时，把不定参数原样转交给 printf 体系。

**试一试**：① 写 `double avg(int count, ...)` 求不定个整数的平均值（va_arg 逐个取、累加除以 count）；② 把 `va_end` 注释掉跑一次——多数平台无感，但它是标准要求的三件套纪律（007 §7.7 的 free 配对同款思想：拿到的资源要有明确的"用完"动作）。

## 9.5 坑表

| # | 现象 | 原因 | 解法 |
|---|---|---|---|
| 1 | 不带参数裸跑就崩 | 直接取 `argv[1]`，参数不存在 | 先判 `argc > 1` 再用（§9.1） |
| 2 | 命令行数字当数字算出错 | argv 里全是字符串 | `atoi`/`sscanf` 先转（§9.3） |
| 3 | sprintf 后程序诡异崩溃 | 目标缓冲区装不下（不查容量） | 预估长度；工程用 `snprintf(str, sizeof str, ...)` 限长（权威参考见 cppreference） |
| 4 | sscanf 只解析到一半 | 格式串字面锚与源串不匹配（空格宽容、字面字符苛刻） | 逐字符核对字面锚；用返回项数判断 |
| 5 | sscanf 的 `%s` 只拿到一个词 | `%s` 遇空白即停（008 §8.7 坑 2 同源） | 扫描集 `%[...]` 或按锚分段解析 |
| 6 | va_arg 取出来的值是垃圾 | 类型与实参不一致（char/short 已提升为 int） | 按提升后的类型取参（002 §2.2） |
| 7 | 变参函数编译报错或行为异常 | `...` 前没有固定参数 | 至少留一个固定参数当路标 |
