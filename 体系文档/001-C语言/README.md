# C 语言手册

> **一句话**：C 是嵌入式的母语——直接操作内存、贴着硬件跑；本板块从第一个程序立到数据结构容器与算法，是全库的语言地基。  
> **读者**：零基础或语法残缺的嵌入式初学者；从运维/软件方向转行、想补"软硬结合"地基的工程师。  
> **口径**：C17 主线（C11/C23 差异注记），演示用 GCC（Windows 装 MinGW-w64，Linux/macOS 自带），编辑器 VS Code，不绑定 IDE。  
> **更新**：2026-11-19  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。

## 体系总览

十四册一条线，按**依赖顺序**而非知识点热度排：先让程序跑起来（001），再掌握语言主干与类型细节（002）。接着按"**数据 → 逻辑 → 地址**"补三块地基——同类型数据怎么装进连续格子（003 数组与字符串）、逻辑怎么组织成函数且变量在哪活着（004 函数与作用域），然后才攻嵌入式第一关：地址、指针与内存模型（005）。指针玩熟后进到工程级用法与堆（006），再回到"把数据摆进内存"的组织层——结构体/位域/枚举与预处理（007）。语言地基到此立完，接两条对外接口：文件 IO（008）与命令行参数、字符串格式化（009）。最后把地基变成工具箱，按"**先量尺、再装数据、再做操作、最后加速查找**"排：复杂度的尺子（010）→ 动态数组与链表（011）→ 栈与队列（012）→ 查找与排序（013）→ 散列与红黑树（014）。

## 阅读约定

1. **口径行声明版本**：每册头部写明标准与工具基线；跨版本差异在正文注记。
2. **代码可复制运行**：每个示例最小可编译，写明预期输出；危险用法 ⚠️ 标注。
3. **每册结构统一**：目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
4. **跨册引用带册号**：如「计算机体系结构」003——所指章节必须真实存在。
5. **教学节带跟学四件套**：完整示例 → 预期输出（本机实测回填）→ 跟做步骤 → 试一试；"能看懂"不算完成，"能跟着做"才算。
6. **重点标记**：节标题带 ★（必会）/ ○（拓展）；每册开头导读块给出必会三点与跟做时长——时间紧只啃 ★。
