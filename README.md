# es-document · 嵌入式入门知识库

> **这是什么**：一套面向嵌入式初学者的体系化知识库——软件三层地基（C 语言、计算机体系结构、操作系统原理）+ 硬件两层（硬件基础、数字电路），5 板块 62 册正文（另 5 册板块全貌），每册对应一类真实学习任务；后续向 MCU 与外设、RTOS、嵌入式 Linux 逐步扩建。  
> **读者**：想入门软硬结合嵌入式的初学者，以及从运维/软件方向转行、需要系统补底层的工程师。  
> **怎么用**：顺序读当教材，按目标选路补缺口，按册查当手册，术语表与症状反查当字典——四种用法对应四种阅读场景。  
> **更新**：2026-11-27 · 库名定为 `es-document`、教材目录改为 `es-docs-001-体系文档/`、新增台账目录 `es-docs-901-碎片文档/`；内容仍为 62 册正文 + 5 册全貌 · 5 份术语表 · 80 张手写 SVG 配图（77 张 1200 宽 + 3 张外部原理图原尺寸）


## 按目标选路（四条捷径）

上方主线是"从零到软硬结合"的顺序。如果已经有明确目标，按下面四条选一条走——每条只读必要册，并写明**可以跳过什么**。选路不是抄近道：**"前置"那行满足不了就先补**，跳过的册在卡住时回补。

**① 会写 C，但看不懂电路图**
- 读：「400 硬件基础」410 电学基础 → 420 电路拓扑 → 430 无源器件 → 440 半导体器件 → 450 板级实践（五个模块全读，15 册）；「500 数字电路」511 逻辑门与数字信号 → 521 加法器与运算器
- 前置：C 111 编译四阶段与第一个程序、C 121 变量类型与运算符（位运算）
- 跳过：「300 操作系统原理」全板块；C 131~165
- 再往前走：接 500 的 531 → 541 → 551（前置链就是 511→521，接着读不断层）

**② 想知道程序在硬件上到底怎么跑**
- 读：「200 体系结构」221 上电与内存布局 → 222 指令周期与软件延时 → 231 MCU 存储速度阶梯；「300 操作系统」311 四大职责 → 312 启动链 → 313 系统调用 → 321 进程模型 → 322 线程 → 323 竞态 → 331 中断 → 332 调度
- 前置：C 111（能编译出 .o 做反汇编）
- 跳过：「400 硬件基础」「500 数字电路」全板块；C 131~165（想深挖"变量到底放哪"，再补 C 133 → 141）

**③ 想搞裸机与 MCU（面向规划中的 600）**
- 读：「400 硬件基础」410 → 420 → 430 → 440 → 450（全 15 册）；「500 数字电路」502 全貌 → 511 → 521 → 531 → 541 → 551
- 前置：C 121（位运算）；要用位域写寄存器映射，先补 C 133 指针 → C 132 结构体与位域（132 的前置正是 133）
- 跳过：「300 操作系统原理」全板块（留到 700 RTOS 之前读）；C 151~165

**④ 只想排查内存与性能问题**
- 读：C 121 → 131 → 123 → 133 → 141 → 142（141 的前置是 133、142 的前置是 141，这条链跳不得）；「200 体系结构」211 → 221 → 222 → 231；「300 操作系统」321 → 323
- 前置：C 111
- 跳过：「400 硬件基础」「500 数字电路」全板块；C 124 / 143 / 151~165（动态数组的性能另看 C 162）

**怎么用这四条**：先看"前置"那行，满足不了先补，别硬上；再看"跳过"那行，它比读什么更能决定你能走多远。**主线用来打地基，选路用来补缺口**。四条里反复出现的只有三处：C 121（位运算，三条路的前置）、C 133（指针与地址，一条路的前置 + 一条路的正文）、体系结构 231（存储速度阶梯，两条路的正文）——时间紧就优先补这三处，复用率最高。

## 贯穿全库的四条主线

跨板块反复出现的概念——在一处立住，处处引用：

1. **同一件事，两层解释**：C 说"变量"，机器层说"一段地址 + 一个段"；C 说"函数调用"，机器层说"压栈 + 改 PC"。看代码时多问一句"芯片在干什么"——体系结构 221 §221.1 的两条路线（指令与数据放不放一起）是这一切布局问题的地基。
2. **内存思维一条线**：C 141 的四区 → 体系结构 231 的存储阶梯 → OS 321 的进程记账——同一件事的三层递进。
3. **裸机到 OS 的两种形态**：中断与并发的两副面孔——体系结构 223/231 立硬件机制，OS 331 §331.5 给出裸机/RTOS/Linux 对照。
4. **每册一个最小实验**：编译一个程序、拆一段反汇编、跑一次遍历计时——不动手等于没学。
