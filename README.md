## 学习路径（初学者 → 软硬结合）

```plain
第一站 · C 语言        001 环境与编译四阶段 → 002 语法与位运算 → 003 指针与内存模型
第二站 · 体系结构      001 抽象塔与硬件形态 → 002 CPU 与指令集 → 003 存储层次与缓存
第三站 · 操作系统      001 职责与启动 → 002 进程与线程 → 003 中断与系统调用
后续 · 规划中          004 电子电路 → 005 MCU 与外设 → 006 RTOS → 007 嵌入式 Linux（编号已预留）
```

原则：**每一站的地基都在前一站**——指针的地址直觉立在 C 003，存储层次给它硬件解释（体系结构 003），进程内存建在两者之上（OS 002）。跳站读会缺一层直觉。**目录前缀就是这条路线的板块顺序。**

## 贯穿全库的四条主线

跨板块反复出现的概念——在一处立住，处处引用：

1. **抽象层级**：每个概念都问"它在塔的哪一层"——C 的指针落在体系结构的地址上，进程落在 OS 的抽象上（体系结构 001 §1.1 是总纲）。
2. **内存思维一条线**：C 003 的栈堆 → 体系结构 003 的存储层次 → OS 002 的进程记账——同一件事的三层递进。
3. **裸机到 OS 的两种形态**：中断与并发的两副面孔——体系结构 002/003 立硬件机制，OS 003 §3.5 给出裸机/RTOS/Linux 对照。
4. **每册一个最小实验**：编译一个程序、拆一段反汇编、跑一次遍历计时——不动手等于没学。

1. **每册结构统一**：目录 → 正文（每节开头直接给定义/结论，不强制承接句）→ 坑表 → 检查清单 → 下一篇。
