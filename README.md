> **怎么用**：顺序读当教材，按册查当手册，术语表与症状反查当字典——三种用法对应三种阅读场景。

## 学习路径（初学者 → 软硬结合）

```plain
第一站 · C 语言        001 环境与编译 → 002 语法与位运算 → 003 数组与字符串 → 004 函数与作用域 → 005 指针与内存模型 → 006 指针进阶与动态内存 → 007 结构体位域与预处理 → 008 文件IO → 009 命令行参数与字符串格式化 → 010 时间与空间复杂度 → 011 动态数组与链表 → 012 栈与队列 → 013 查找与排序 → 014 散列与红黑树
第二站 · 体系结构      001 抽象塔与硬件形态 → 002 CPU 与指令集 → 003 存储层次与缓存
第三站 · 操作系统      001 职责与启动 → 002 进程与线程 → 003 中断与系统调用
第四站 · 硬件基础      001 电学与欧姆定律 → 002 元器件与参数识别 → 003 半导体与分立器件 → 004 电路实践与板级应用
```

原则：**每一站的地基都在前一站**——指针的地址直觉立在 C 005，存储层次给它硬件解释（体系结构 003），进程内存建在两者之上（OS 002）。跳站读会缺一层直觉。**目录前缀就是这条路线的板块顺序。**

## 贯穿全库的四条主线

跨板块反复出现的概念——在一处立住，处处引用：

1. **抽象层级**：每个概念都问"它在塔的哪一层"——C 的指针落在体系结构的地址上，进程落在 OS 的抽象上（体系结构 001 §1.1 是总纲）。
2. **内存思维一条线**：C 005 的栈堆 → 体系结构 003 的存储层次 → OS 002 的进程记账——同一件事的三层递进。
3. **裸机到 OS 的两种形态**：中断与并发的两副面孔——体系结构 002/003 立硬件机制，OS 003 §3.5 给出裸机/RTOS/Linux 对照。
4. **每册一个最小实验**：编译一个程序、拆一段反汇编、跑一次遍历计时——不动手等于没学。
