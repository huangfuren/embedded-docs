## 二、不装什么（该去别处）

| 内容 | 去处 |
| --- | --- |
| 讲原理、能当课本顺序读的教材型内容 | `es-docs-001-体系文档/` 对应板块 |
| 一句话待办 / 缺口 / 待核实 | `_issues/`（015，一条一文件） |
| 已定版、不需要再跟进的结论 | `.agents/memorys/`（014） |

> 判不准时：先问「半年后有人会从头读它当教程吗」——会，进 `001`；不会但还要查，进这里。

## 三、命名（011 双命名法，混用一种必乱）

| 内容性质 | 命名 | 维护方式 |
| --- | --- | --- |
| 快照：某时某地发生的一件事、一次排障、一次调研、一场会 | `YYYYMMDD-主题.md` | **只增不改**；要修正结论另起「更正」段并注日期 |
| 快照且由 AI 生成 | `YYYYMMDD-HHMMSS-AI名-主题.md` | 同上，AI 名保持稳定以便追溯 |
| 长期有效的现状 / 清单（权威底账） | `NNN-主题.md` | 头部标「**权威-持续维护版**」，随现状改 |

- 主题用中文，不用空格；**禁 `: / \ * ? " < > \|`**（同 002 文件名规则）。
- 稳定对象才用 `NNN-`；**数字一旦占用不回收**。

## 四、落位与配图

- **默认平铺在本目录**，不为单篇建子目录；同类超过 5 篇再按主题建 `NNN-主题/` 子目录收拢。
- 排障复盘的原始日志、命令输出按 011 §三 放同级 `raw_data/`——**原始证据与结论分层**，结论可被推翻，证据不能丢。
- 配图放同级 `images/`，文件名 `YYYYMMDD-HHMMSS-mmm.扩展名`（毫秒防重名），正文用相对路径嵌入。

## 五、🔴 脱敏铁律（011 引言）

真实 IP / 主机名 / 网段 / 账号 / 口令 / 内部系统名，**写入前一律替换为虚构值**；AI 整理时遇敏感信息用 `<REDACTED>` 占位，不摘录原文。本库将来可能被示人，带着真实生产指纹的记录是安全隐患。
