# 硬件基础手册

> **一句话**：电是嵌入式的物理底座——从电荷怎么流、电阻怎么读数，到半导体为什么能当开关，最后把元件拼成一块能跑 MCU 的板子；看懂这一层，芯片手册里每一句"接个上拉""加个去耦"才不是咒语。  
> **读者**：纯软件背景转嵌入式、没摸过万用表的初学者；想看懂开发板原理图的工程师。  
> **口径**：只讲直流与低压（≤5V）实验；元件参数给典型值并注明"以 datasheet 为准"；模拟电路讲到"能看懂、会用开关"为止，不做偏置设计与频率分析。

## 核心概念速览

- **电流的本质是电荷定向移动**：规定正电荷方向为电流方向，金属里跑的电子方向相反——按定义分析，不要中途换向（411）。
- **三要素被一个定律锁死**：电压是推力、电流是流量、电阻是阻碍，U=IR 把三者绑在一起；一切电路计算从这儿出发（412）。
- **丝印有三套规则**：`103` 是三位法（10kΩ）、`1002` 是四位法（10kΩ）、`10E` 是 EIA-96（1.24MΩ）——先数位数，再决定查不查表（431）。
- **PN 结的单向导电来自耗尽层**：正偏变窄导通、反偏变宽截止，不是"阀门"的比喻（441）。
- **三极管靠电流控制、MOS 靠电压控制**：前者 B 极持续耗流，后者栅极绝缘几乎不耗；芯片里的"原子"是 MOS（442 / 443）。
- **最小系统恒为四件**：供电+去耦 / 复位 / 时钟 / BOOT，缺一件就不算能跑（451）。

## 学习路径

**顺序读**：410 → 420 → 430 → 440 → 450——先电、再连法、再元件、再器件、最后成板。**跳层会缺直觉**：跳过 440 直接看 MOS 电路图，会完全读不懂；跳过 430 直接读原理图，只认得出一堆方块。

**按任务找册**：

**按症状进**：见 [401 术语表](401-术语表.md) 的症状反查表——板子不行为先查表，不要盲拆。

**只关心嵌入式（不碰 PCB 设计）**：411 → 412 → 421 → 422 → 431 → 441 → 442 → 451 → 452。**这条线省掉 413/420 的部分、432/433 的器件细节与 443**，代价是遇到电容去耦与 MOS 驱动时要回来补。

**动手纪律**：十五册各配可上手的动作——算一道题、读五个丝印、画一张 PN 结、数清开发板四件、在仿真里搭一个光感灯。

## 误解澄清

| # | 误解 | 实际 |
| --- | --- | --- |
| 1 | 电压和电流是一回事 | 推力与流量，U=I×R 锁死（411） |
| 2 | 电子的流动方向就是电流方向 | 定义相反：规定正电荷方向为正（411） |
| 3 | 电阻会"跟着电压变" | 阻值由材料与几何决定，不随电压电流变（411） |
| 4 | 电阻值随便选，反正都能用 | 功率不核算会烧，差一个量级电流差十倍（412） |
| 5 | 低电压绝对安全，可以随便短路 | 危险的是电流；短路时电流只受内阻限制（413） |
| 6 | 分压电路能给传感器供电 | 只能取信号，带载就被拉低（421） |
| 7 | 上拉电阻是种特殊元件 | 就是普通电阻，名字来自用法（422） |
| 8 | 悬空的输入脚读到 0 | 读到的是随机态，不是 0（422） |
| 9 | 电容 `104` 是 104pF | 是 `10×10⁴ pF = 100nF`（432） |
| 10 | `10E` 和 `103` 差不多 | 差 124 倍：`10E`=1.24MΩ，`103`=10kΩ（431） |
| 11 | 三极管和 MOS 可以随便替换 | 一个电流控制、一个电压控制，驱动电路完全不同（443） |
| 12 | PNP 和 NPN 只是画法不同 | 导通电平相反、电流方向相反（442） |
| 13 | 三极管应该工作在放大区才"正常" | 做开关时必须故意进饱和，停在放大区会发烫（442） |
| 14 | 去耦电容是装饰，省了没事 | 省了会偶发复位，且故障极难查（432） |
| 15 | LED 接上 3.3V 就能亮 | 必须串限流电阻，否则瞬间过流烧毁（412） |
| 16 | 仿真通了实物就没问题 | 仿真验拓扑，实物验实现（容差、寄生、接触）（454） |

## 阅读约定

1. **安全红线**：全部实验限于低压直流（≤5V）；市电 220V 与大电流一概不写不做（⚠️ 413）。
2. **参数给典型值**：LED 压降 2V、上拉 10kΩ、去耦 0.1μF 都是工程惯例值，正式设计以 datasheet 为准。
3. **每册结构统一**：导读块 → 目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
4. **跨册引用带册号**：如「442 §442.5」——所指章节必须真实存在。
5. **跟做分两路**：纸面作业（画图、算题、读丝印，任何机器都能做）与实物观察（有面包板/万用表/开发板才做，无器材按纸面路径完成）。
6. **数学只到乘除**：除焦耳定律的平方项外不出现复杂公式；感抗与容抗只给公式不做复数运算。
