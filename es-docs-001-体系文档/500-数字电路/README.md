# 数字电路手册

> **一句话**：数字电路回答"0 和 1 在导线上一副什么模样"——用什么电压算 1、用什么门能把两个数加起来、用什么单元能把一位状态记住、又怎么把这几件零件接成一台能跑程序的机器。  
> **读者**：学完「400 硬件基础」、已经认识二极管三极管 MOS 的初学者；想弄懂"位运算在硬件层到底做了什么"的软件工程师。  
> **口径**：以 3.3V CMOS 系统为例；电平与阈值给典型值，判定标准以具体芯片 datasheet 为准；不做门级电路设计与时序分析（那是数字 IC 设计）。  
> **更新**：2026-11-23  
> **术语表**：单独成册 → [501 术语表](501-术语表.md)。

## 核心概念速览

- **0/1 是两段电压区间**，中间是禁止区；噪声只要不把电平推出区间，值就不变——数字电路抗干扰的本钱（511）。
- **组合逻辑看现在，时序逻辑看历史**：差别就在有没有"输出接回输入"的反馈（512 / 531）。
- **记忆的进化是"把何时能改钉得越来越死"**：无控制端 → 电平使能 → 时钟边沿（531 / 532）。
- **地址决定谁说话，使能决定准不准说**——存储器、寄存器、GPIO 全是这一套（541 / 542）。
- **指令 = 做什么 + 对谁做**；PC 是一个每次加一的累加器，程序才走起来（552 / 553）。

## 学习路径

**① 顺序读**：先「400 硬件基础」440 认完器件，再进本板块 511 → 512 → 521 → 522 → 523 → 531 → 532 → 533 → 541 → 542 → 551 → 552 → 553。**五模块是一条线，跳读会断。**

**② 按症状进**：见 [501 术语表](501-术语表.md) 的「症状反查」表——24 条常见症状各自指向责任册。

**③ 按需求走捷径**：

| 你的目标 | 最短路径 |
|---|---|
| 只想弄懂"0 和 1 是什么、门怎么工作" | 511 → 512 |
| 想懂"位运算在硬件层做了什么" | 512 → 521 → 522 |
| 想懂"寄存器、缓存那些名词" | 531 → 532 → 533 |
| 想懂"内存条为什么按地址访问" | 523 → 541 → 542 |
| 想懂"CPU 怎么跑程序"（最热门的问法） | 551 → 552 → 553 |

**动手纪律**：真值表、加法器、ALU、锁存器、寄存器、存储器、CPU 全都能用 C 跑出来（`gates.c` / `adder.c` / `alu.c` / `latch.c` / `reg.c` / `mem.c` / `cpu.c`，各附册末），**不用买芯片也能完成**。

**读到哪算够**：能自己解释"`13+6+27−6` 这五条指令为什么能算对、结果为什么落在地址 3"，数字电路这一层就算通了（553 §553.4）。

## 误解澄清

| # | 误解 | 实际 |
|---|---|---|
| 1 | 数字 0 就是"没电" | 0 是一段低电压区间，不是 0V 也不是断电（511） |
| 2 | 电平判定标准全宇宙统一 | TTL 与 CMOS 阈值不同，跨电平必须查 datasheet（511） |
| 3 | 悬空的输入脚默认是 0 | 落在禁止区，是高阻随机态（511；400 硬件基础 422） |
| 4 | 真值表只能背 | 四行跑一遍程序就出来，还能自己补 NAND 列（512） |
| 5 | 加法器位数越多越好算 | 行波进位下位宽越大越慢，最高位要等前面所有进位（521） |
| 6 | 锁存器和触发器是一回事 | 前者电平敏感（en 期间透明），后者边沿触发（531 / 532） |
| 7 | 寄存器就是"存一个数" | 它靠共用时钟保证多位是同一瞬间的快照，还要复位（533） |
| 8 | 存储器和寄存器只是大小不同 | 数量、寻址方式、端口数都不同：寄存器编号写在指令里（533 / 542） |
| 9 | 存储器"存进去就能读出来" | 要有正确地址、片选、写使能，还要守时序（541） |
| 10 | 控制器就是 CPU | CU 只是 CPU 里负责"喊开始、发信号"的那一块（551 / 552） |
| 11 | 程序靠软件自己往下走 | PC 的 +1 是硬件连线；靠软件改地址会无限倒退（553） |

## 阅读约定

1. **每册结构统一**：导读块 → 目录 → 正文（每节开头直接给定义/结论）→ 坑表 → 自测 6 题 + 动手任务。
2. **实验全部走软件仿真**：所有程序用 `gcc` 在本机跑，**不需要买芯片**——这个板块是纯软件也能学完的。
3. **打印的输出都是真跑出来的**：每册"预期输出"都是本机实测，不是编出来好看的；数字对不上就是自己抄错了。
4. **跨册引用带册号**：如「532 §532.4」——所指章节必须真实存在。
5. **阈值不作定论**：3.3V CMOS 的 2.0V / 0.8V 是典型值，跨电平系统一律查 datasheet。
6. **先有直觉再进公式**：噪声容限、建立保持时间这类概念先给画面感，公式留到需要时再引。
