# 201 术语表

> **这一文档回答**：本板块词汇的准确定义、两个混用词的分界、「症状出现时病根在哪」往哪走。
> **怎么用**：按名字（按册分组）、按缩写（缩写速查）、按症状（症状反查）。
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

### 211 补码与整数范围

| 术语 | 英文 | 一句话 |
|---|---|---|
| 字长 | Word Size | CPU 一次处理的位数，决定寄存器宽度与地址宽度 |
| 原码 | Sign-Magnitude | 最高位当符号位、其余是绝对值——有"两个零" |
| 反码 | Ones' Complement | 负数按位取反——也有"两个零"，减法要循环进位 |
| 补码 | Two's Complement | 负数按位取反再加一；唯一零，加法电路通吃加减 |
| 无符号回绕 | Unsigned Wrap-around | 标准规定必然发生的取模回绕（`0u-1 = 4294967295`） |
| 有符号溢出 | Signed Overflow | 结果是未定义行为（UB），换编译器就可能变脸 |

### 212 浮点精度与字节序

| 术语 | 英文 | 一句话 |
|---|---|---|
| IEEE 754 | IEEE 754 | 浮点的位布局标准：符号 + 指数 + 尾数 |
| 尾数 | Mantissa | 决定精度：单精度 23 位，只够约 7 位十进制有效数字 |
| 精度天花板 | Precision Limit | 单精度在 `2²⁴` 之后 `+1` 不再生效 |
| 比较容差 | Epsilon | 浮点比较用 `fabs(a-b) < eps`，不用 `==` |
| 大端 | Big-endian | 高位字节放低地址（Modbus、网络字节序） |
| 小端 | Little-endian | 低位字节放低地址（x86、Cortex-M） |
| 字节序转换 | Byte Swap | `bswap` / `__REV` 一类指令，跨平台传多字节值必做 |

### 221 上电与内存布局

| 术语 | 英文 | 一句话 |
|---|---|---|
| 冯·诺依曼结构 | von Neumann Architecture | 指令与数据共用存储器，靠缓存调和 |
| 哈佛结构 | Harvard Architecture | 指令与数据分开存储，MCU 的标准形态 |
| `.data` | Data Section | 有非零初值的可写变量：占镜像，上电要搬进 RAM |
| `.bss` | Block Started by Symbol | 零初始化变量：不占镜像，上电清零即可 |
| `.rodata` | Read-only Data | `const` 与字符串：留在 Flash，不搬不占 RAM |
| 启动代码 | Startup Code | 复位后搬 `.data`、清 `.bss`、跳 `main` 的那段汇编 |
| 链接脚本 | Linker Script | 规定各段放哪个地址、边界符号叫什么 |
| noinit 段 | No-init Section | 启动代码不碰的段，用于跨复位保留数据 |
| map 文件 | Map File | 编译产物账单：Code / RO / RW / ZI 四个数字 |

### 222 指令周期与软件延时

| 术语 | 英文 | 一句话 |
|---|---|---|
| 程序计数器 | Program Counter | 存"下一条指令地址"；一切岔路都是改它 |
| 指令周期 | Instruction Cycle | 取指 → 译码 → 执行 → 改 PC 的循环 |
| 机器码 | Machine Code | CPU 直接认的二进制；反汇编列里的十六进制就是它 |
| 汇编语言 | Assembly Language | 机器码的助记符形式，与指令一一对应 |
| 寻址方式 | Addressing Mode | 操作数在哪：立即 / 寄存器 / 直接 / 间接 / 变址 / 偏移 |
| 指令集架构 | ISA | 软件与硬件之间的契约；同 ISA 可有多种微架构实现 |
| CPI | Cycles Per Instruction | 每条指令平均花的周期数，等待周期会把它推高 |
| 中断延迟 | Interrupt Latency | 从事件到 ISR 第一条指令执行，通常在十几周期量级 |

### 223 中断与异常

| 术语 | 英文 | 一句话 |
|---|---|---|
| 中断 | Interrupt | CPU 外部的异步事件（外设、定时器）强制改 PC |
| 异常 | Exception | CPU 执行中自己发现的同步事件（除零、非法访问） |
| 向量表 | Vector Table | 固定地址的一张"事件 → 处理函数入口"映射表 |
| ISR | Interrupt Service Routine | 中断服务函数：必须短、不阻塞、不可重入 |
| 现场保存 | Context Save | 进入 ISR 前把寄存器压栈，返回时恢复 |
| 抢占 | Preemption | 高优先级中断打断低优先级 ISR |

### 231 MCU 存储速度阶梯

| 术语 | 英文 | 一句话 |
|---|---|---|
| SRAM | Static RAM | 片内静态存储器，通常 0 等待，变量与栈住这里 |
| Flash | Flash Memory | 非易失程序存储器，读取有等待周期，按块擦写 |
| 等待周期 | Wait State | 主频超过 Flash 上限后每次取指要多等的周期 |
| `FLASH_ACR` | Flash Access Control Register | 配等待周期的寄存器，必须在提频之前设好 |
| `__ramfunc` | RAM Function | 把函数搬进 RAM 执行，绕开 Flash 等待 |
| DMA | Direct Memory Access | 外设与内存直接搬运，CPU 只发一次指令 |
| I-Cache / D-Cache | Instruction/Data Cache | Cortex-M7 才有的指令/数据缓存 |
| cache 一致性 | Cache Coherence | DMA 与 cache 视图不一致，必须 clean/invalidate |

## 缩写速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| ISA | Instruction Set Architecture | 指令集架构：软硬件契约 |
| ALU | Arithmetic Logic Unit | 算术逻辑单元，真正做运算的部件 |
| MCU | Microcontroller Unit | 微控制器：Flash + SRAM + 外设的单芯片 |
| SoC | System on Chip | 片上系统：MCU 的放大版 |
| DMA | Direct Memory Access | 绕过 CPU 的搬运通道 |
| ISR | Interrupt Service Routine | 中断服务函数 |
| NVIC | Nested Vectored Interrupt Controller | Cortex-M 的中断控制器（嵌套 + 向量化） |
| CPI | Cycles Per Instruction | 每条指令平均周期数 |

## 易混对

| A vs B | 分界一句话 |
|---|---|
| 冯·诺依曼 vs 哈佛 | 指令数据同存储 vs 分存储；PC 是演化混合体，Cortex-M 是标准哈佛 |
| 中断 vs 异常 | 来自 CPU 外部、异步 vs 由 CPU 自己发现、同步 |
| `.data` vs `.bss` | 初值非零、占镜像 vs 初值全零、不占镜像 |
| Flash vs SRAM | 断电留、只读、有等待 vs 断电丢、可写、0 等待 |
| 有符号溢出 vs 无符号回绕 | UB（结果不定）vs 标准规定必然回绕 |
| 大端 vs 小端 | 高位字节在低地址 vs 低位字节在低地址 |
| 机器码 vs 汇编 | 同一东西：CPU 认的二进制 vs 人读的助记符 |
| 程序计数器 PC vs 个人电脑 PC | CPU 里的寄存器 vs 那台机器——上下文定含义 |

## 症状反查

| 症状 | 最可能病根 | 去哪册哪节 |
|---|---|---|
| 全局变量上电初值不对 | 启动代码搬运段没执行 / `_sidata` 指错 | 221 §221.2 |
| 复位后某个变量居然保留了旧值 | 它被放进了 `noinit` 段 | 221 §221.3 |
| RAM 没超但 Flash 超了 | RW-data 同时占 Flash 与 RAM | 221 §221.3 |
| 调试版延时正常，发布版全乱 | `-O2` 把空循环整段删掉 | 222 §222.3 |
| GPIO 翻转频率远低于标称主频 | 三条指令 + Flash 等待 + 总线分频 | 222 §222.3 / 231 §231.2 |
| 提高主频后程序跑飞 | `FLASH_ACR` 等待周期没同步调高 | 231 §231.2 |
| 串口/Modbus 多字节值拼反了 | 大端寄存器当小端读 | 212 §212.3 |
| `uint16_t` 减法结果变成 65535 | 无符号回绕，差值为负 | 211 §211.3 |
| ISR 里调 `printf` 就死机 | ISR 不可重入、阻塞 | 223 §223.2 |
| 程序"突然"跳到别处执行 | 中断打断了主流程 | 223 §223.1 |
| 死机后不知道停在哪 | 没查向量表与故障状态寄存器 | 223 §223.3 |
| DMA 搬完了但读出来是旧值 | D-Cache 没 invalidate（M7） | 231 §231.5 |
